# The Playbook

A single-file self-study reference across the [tritsystem](https://github.com/tritsystem)
portfolio — a chronological, from-scratch walkthrough of one substrate underneath most of the
repos, built to defend the work under questioning, not just recognize it.

Every claim in it is a real, measured number pulled directly from the corresponding repo —
no rounding up, no smoothing over negative results.

## What it is

A static `index.html` — open it directly in a browser, no build step, no dependencies.
